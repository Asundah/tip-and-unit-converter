# Tip Calculator & Unit Converter

Two utilities in one page: a tip calculator and a unit converter (length, weight, temperature). Built with plain HTML, CSS, and JavaScript.

## Features

### Tip Calculator

- Enter bill amount, tip percentage, and number of people
- Real-time calculation of per-person total

### Unit Converter

- **Length:** meters, kilometers, miles, feet, inches
- **Weight:** kilograms, grams, pounds, ounces
- **Temperature:** Celsius, Fahrenheit, Kelvin

### Validation

- Rejects negative bill amounts
- Requires at least 1 person for splitting
- Inline error messages for invalid input
